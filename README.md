# 🏪 商业巨子：白手起家

2.5D（等距视角）商业模拟网页游戏。纯原生 **HTML / CSS / JavaScript**，不依赖任何构建工具（没有 webpack / npm build），
双击 `index.html` 或丢到任意静态网页托管上就能玩，可部署到任意静态网页托管。

三个阶段：**白手起家 → 商业扩张 → 资本帝国**（当前已实现全部三阶段的可玩版本，详见下方）。

---

## 🎮 在线试玩

仓库推到 GitHub 并开启 Pages 后（见下方「部署到 GitHub Pages」），地址形如：

```
https://<你的GitHub用户名>.github.io/<仓库名>/
```

## 💻 本地运行

不需要安装任何依赖，两种方式任选：

1. **直接双击** `index.html` 用浏览器打开（Chrome/Edge/Firefox 均可）。
2. 或起一个本地静态服务器（部分浏览器对 `file://` 下的某些 API 有限制，建议用这种方式）：
   ```bash
   npx http-server -p 8080 -c-1
   # 然后浏览器打开 http://localhost:8080
   ```

**为什么用原生 `<script>` 而不是打包工具？** 为了部署简单：GitHub Pages 直接托管这些静态文件即可运行，
不需要任何 CI 构建步骤。`index.html` 底部的 `<script>` 加载顺序就是模块依赖顺序（core → phase1 → phase2 → phase3 → ui）。

## 🕹️ 玩法速览

- **每日时间**：6:00–24:00，每个行动消耗若干小时，超时自动睡觉结算（房租/伙食/熬夜惩罚/商品过期）。
- **三条状态**：体力 / 精力 / 健康，过低会降低打工与摆摊效率。
- **五条起步路径**：临时工、技能工作、低买高卖、摆摊、开店，互相支撑，自由组合。
- **三个里程碑**：净资产 ¥1,000 → 更多交易机会；¥3,000 且生意持续盈利 → 店铺与员工；
  ¥10,000 且生意正常经营 → 自动成立公司，进入第二阶段「商业扩张」。
- **第二阶段**：多店铺、员工招聘培训、批发仓库、银行贷款与信用评级、区域竞争与品牌声望、每日/月度财报。
- **第三阶段金融市场**（开局即可交易，不设资产门槛）：
  - **6 只虚拟股票**（新港重工/滨海地产/云港科技/新辉零售/港源能源/创想医药），覆盖工业、地产、
    科技、零售、能源、医药六个行业，各自设定了**总股本、流通盘与流通比例**（流通盘 0.9亿～8亿股，分大/中/小盘股，界面显示流通市值与换手率）、波动率与贝塔系数，
    流通盘越小波动越大、也更容易被大额买卖冲击价格；每约45天发布一次**季度财报**（营收/净利/EPS），
    financial surprise 会直接触发股价跳空；并有覆盖六大板块的**突发事件/黑天鹅新闻池**。
  - **商品期货**（大豆/螺纹钢/原油/黄金），5–10倍保证金交易，每日盯市结算，保证金不足会被强制平仓。
  - **外汇**（美元/欧元/日元兑新港元）。
  - **跨系统联动**：第一阶段的商品价格事件（如「蔬菜暴涨」）会直接影响对应期货/个股的价格。
- **解锁条件、数值参数**全部集中在 `js/core/config.js`，调数值不用碰逻辑代码。
- 游戏在每晚睡觉后自动存档到 `localStorage`，也支持 3 个手动存档槽位。

## ☁️ 云存档配置（Cloudflare Pages，只需一次，约 5 分钟）
1. Cloudflare 控制台 → **Workers & Pages** → **KV** → **创建命名空间**，名字随意（例如 `bt-saves`）。
2. 打开你的 Pages 项目（business-tycoons）→ **设置** → **函数 / Bindings** → **添加绑定 → KV 命名空间**：
   变量名填 **`BT_SAVES`**，命名空间选刚才建的那个。生产环境和预览环境都加上。
3. 重新部署一次（推送代码或在控制台点「重试部署」）。仓库里的 `functions/api/save.js` 会自动变成 `/api/save` 接口。
4. 游戏里「存档」页 → 云存档：填存档码 + 密码 → 上传；在 iPad 上填同样的存档码和密码 → 下载。
   没配置 KV 时，点上传会提示「云存档还没配置」，其他功能不受影响。

## 更新记录（v6：奢侈品 / 进口贸易 / 区域客群 / iPad）
- **区域客群**：每个区对每个品类有需求倍率（🔥热销 / ❄滞销）和价格敏感度。热销品被挑中、成交都更多；滞销品看的人少、买的更少；
  城中村、学院区加价很伤销量，商业街可以卖贵。门店卡片、选址卡片显示本区客群，上架下拉框按热销程度排序。
- **奢侈品**（瑞士名表 / 意式名包 / 珠宝首饰 / 进口名酒 / 香水美妆）：只在公司阶段经营，不能背包倒卖、不能普通批发；
  门店先做「💎 精品装修」（¥15,000，每天安保保险 ¥80）才能上架；有单独的奢侈品买家客流（商业街最旺），节日旺季翻倍，星耀集团所在区域被抢三成。
- **进口贸易**（供应链 → 进口贸易）：价格 = 外币价 × 实时汇率 × (1+关税)(1+增值税)(1+消费税)，表格逐项拆解。
  - 正规进口：先买品牌代理权（90 天，每 30 天配额 30 件，品牌 ≥15），货款当场按汇率付清，在途 4 天，25% 概率被海关查验多等 1~3 天。
  - 水货：不要代理权、不交税（境外零售价拿货），在途 2 天、每单 ≤20 件；每批 12% 概率被查扣（严打 ×3）：没收 + 罚款货值 50% + 品牌/口碑受损；还可能混入假货，卖出后被鉴定出来退一赔半。
  - 新闻：海关严打、临时关税调整；汇率风险可在金融页做外汇对冲。
- **iPad 横屏（761~1366px）**：右栏「背包 + 日志」改成从右边滑出的抽屉（顶栏 🎒📜 按钮），左栏收窄，顶栏两行，金融页下单区放到 K 线下方，按钮加大。

## 更新记录（v5：公司上市）
- **申请上市**（公司页 →「🔔 上市」）：条件 = 门店 ≥3、公司成立 ≥60 天、净资产 ≥ ¥10 万、近 30 天净利 ≥ ¥5,000、信用 ≥660、资产负债率 ≤50%、无资不抵债 / 被收购要约。
  交保荐审计费（估值 1.5%，最低 ¥5,000，不退）→ 审核 10 天（可能被问询延期；期间经营恶化会被否，30 天后可再申请）→ 挂牌。
- **定价发行**：估值 = 门店账面 + 近 30 天利润×12×市盈率（5~15 倍，看品牌和大盘），公开发行 15% 新股，募资扣 3% 承销费后进现金；品牌 +8、信用 +30；解锁结局「敲钟上市」。
- **上市后**：公司成为金融页里的一只股票（标「我的公司」，不能在二级市场自买自卖），季报直接用公司账本的真实营收和利润，
  每天的利润走势、零售板块新闻、新辉零售财报都会带动股价。可以分红（每 30 天一次）；锁定期 90 天后可减持（单次 ≤5%、间隔 ≥15 天、保留 ≥51%）。
  控股股权不按市值计入净资产，减持套现后才变成真钱；上市页单独显示「身价」。
- 信用评级：盈利且无逾期的月份 +6（以前只能靠借贷还款提升）。

- **AI 竞争对手**：星耀集团（高端）、万家连锁（折扣）、新辉零售（上市，股票 XHLS）、远洋商贸（激进高杠杆）。

- **经营 ↔ 金融联动**：新辉零售的门店营收写进 XHLS 季报，份额变化每天影响股价；大盘暴跌/普涨冲击 AI 公司现金，

- **经营深度**：门店三种地段（巷内/临街/路口旺铺）+ 选址客流预估 + 搬迁；一周客流曲线（写字楼区工作日旺、老街码头周末旺）；
  员工销售/服务两项能力、6 种特质、忠诚度与身价（培训后不加薪会掉忠诚、可能辞职或被挖）；人才市场；促销活动；缺货流失统计。
